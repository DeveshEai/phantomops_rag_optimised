============================================================
  PhantomOps Version 4 — Connect the Outlook Mailbox
  Manager Guide
============================================================

This connects PhantomOps to the Microsoft 365 / Outlook mailbox it will read and
reply from. Do it ONCE. It creates a file called  outlook_token.txt  in the
PhantomOps Version 4 folder — that file is PhantomOps's saved permission to use
the mailbox.

------------------------------------------------------------
BEFORE YOU START
------------------------------------------------------------
- PhantomOps Version 4 is installed (you have run install.bat once).
- The three Microsoft app values are already filled into the  .env  file in the
  main PhantomOps Version 4 folder (provided to you):
        OUTLOOK_CLIENT_ID=...
        OUTLOOK_CLIENT_SECRET=...
        OUTLOOK_TENANT_ID=...
  If any are blank, ask whoever provided this package for the values and paste
  them in (open .env in Notepad, save, close).

------------------------------------------------------------
CONNECT THE MAILBOX
------------------------------------------------------------
  1. Double-click  start.bat  in the main PhantomOps Version 4 folder.
     (First run only: because no mailbox is connected yet, it automatically
      opens the Microsoft sign-in. You can also double-click  run.bat  in this
      Outlook-Connector folder to connect on its own.)

  2. A browser window opens with a Microsoft ACCOUNT PICKER.
       - Sign in as the AGENT MAILBOX — the inbox PhantomOps should read and
         reply from (for example agent@yourcompany.com), NOT your personal
         account.
       - If it is not listed, click "Use another account" and sign in.
       - Click Accept on the permissions screen.

  3. The browser shows "PhantomOps is connected" — close that tab.
     outlook_token.txt is now saved in the PhantomOps Version 4 folder.

  4. PhantomOps then starts polling automatically. You should see:
        [EMAIL] Provider: Outlook
        [Init] Mailbox address: <the agent mailbox>
        ... polling ...
     Leave that window open — that is PhantomOps running. To stop it, close it.

------------------------------------------------------------
CHECK IT WORKS
------------------------------------------------------------
  From a different account, send a short email to the agent mailbox. Within
  about 30 seconds PhantomOps should reply.

------------------------------------------------------------
CONNECT A DIFFERENT MAILBOX (switch accounts)
------------------------------------------------------------
  1. Stop PhantomOps (close the start.bat window).
  2. In this Outlook-Connector folder, double-click  signout.bat .
       It removes the current saved token and offers to connect a new mailbox
       right away. Sign in with the new account at the picker.
  (Manual equivalent: delete outlook_token.txt from the PhantomOps folder, then
   run run.bat.)

------------------------------------------------------------
IF SOMETHING GOES WRONG
------------------------------------------------------------
  - "Missing OUTLOOK_CLIENT_ID / _SECRET / _TENANT_ID" : a value in .env is
    blank — paste the values you were given and run again.
  - "Approval required" appears instead of Accept : your IT administrator must
    approve this app once. Click "Request approval" if offered, then run again
    after they approve.
  - "This mailbox is already connected" : a mailbox is already linked. To change
    it, run signout.bat first (see above).
  - The window closes too fast to read : run  run.bat  in this folder instead —
    it stays open and shows any message.

>> KEEP IT PRIVATE: outlook_token.txt gives access to the mailbox. Treat the
   whole PhantomOps Version 4 folder as confidential; never share the token file.
